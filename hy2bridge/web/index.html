Лимит трафика ноды

Параметры лимита

Предупреждения появятся в событиях при 80% и 95%. Лимит считает полезные данные VPN без коэффициента пользователя и сетевых накладных расходов. 1 ТБ = 1000 ГБ. При опросе счётчиков возможен перерасход между замерами.

Учёт начинается при первом включении лимита. Изменение настроек не обнуляет расход. Остановка затрагивает только VPN этой ноды; подписки и лимиты пользователей сохраняются.

Начать новый период этой ноды с нулевого расхода? История трафика и расход пользователей сохранятся. Если VPN был ограничен квотой, доступ возобновится.

Панель и сервер

Управление пользователями, подписками и подключёнными нодами.

CPU и RAM относятся к ОС, видимой панели. Диск — раздел с её данными. Память процесса панели учитывается отдельно.
