Параметры лимита

Лимит относится к VPN-трафику Hysteria2 и VLESS. HTTP/HTTPS-прокси использует отдельные учётные данные и не входит в эту квоту.

Предупреждения появятся в событиях при 80% и 95%. Лимит считает полезные данные VPN без коэффициента пользователя и сетевых накладных расходов. 1 ТБ = 1000 ГБ. При опросе счётчиков возможен перерасход между замерами.

Учёт начинается при первом включении лимита. Изменение настроек не обнуляет расход. Остановка затрагивает только VPN этой ноды; подписки и лимиты пользователей сохраняются.

Начать новый период этой ноды с нулевого расхода? История трафика и расход пользователей сохранятся. Если VPN был ограничен квотой, доступ возобновится.

Проверка подлинности сервера

Отпечаток публичного SSH-ключа сервера. Пароль сюда вводить не нужно. Сверьте значение с данными провайдера или ранее проверенного доступа. Панель будет проверять этот отпечаток при подключении.

Как проверить отпечаток

Попросите отпечаток у провайдера или выполните команду в консоли сервера через доверенный доступ.

ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256

Для другого типа ключа используйте файл ssh_host_ecdsa_key.pub или ssh_host_rsa_key.pub в том же каталоге. Сравните значение SHA256 с отпечатком выше.
